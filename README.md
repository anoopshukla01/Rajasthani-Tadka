## 📖 Overview
**Rajasthani Tadka** is a premium, culturally rich dining web application capturing the authentic gastronomic heritage of Rajasthan, serving genuine woodfire flavours, handcrafted thalis, and pure desi ghee delicacies in Gorakhpur.

---

## ✨ Features

- **🏰 Cultural Branding & Royal Mascot**: Custom-crafted mascot emblem and Devanagari calligraphy inspired by authentic Rajasthani heritage.
- **🎵 Atmospheric Folk Music**: Embedded traditional anthem *"Kesariya Balam"* with custom royal gold audio player, animated audio equalizer, and smooth auto-playback.
- **🍛 Interactive 3D Thaali Orbit**: Engaging visual experience showcasing signature items (Dal Baati Churma, Gatte Ki Sabzi, Ker Sangri, Royal Rajput Laal Maas, and Pushkari Malpua).
- **📜 Scrollytelling Heritage Journey**: Four-stage desert lore from the Thar dunes to the royal banquet hearth.
- **📸 Ambience Gallery & Lightbox**: Compact photo gallery showcasing dining spaces, chandeliers, and royal desserts with fullscreen modal navigation.
- **⭐ Verified Google Reviews (4.8 ★ / 532 Reviews)**: Real customer testimonials with expandable sliding drawer and category filters.
- **📍 Real-Time Location & Interactive Map**: Embedded Google Map pinpointing the restaurant in Daudpur, Gorakhpur, with GPS coordinates and instant directions.
- **📝 Royal Intake & Table Reservation Form**: Elegant editorial reservation interface with instant booking confirmation.
- **👑 Full-Featured Admin CMS Studio (`admin.html`)**: Administrative portal to manage dishes, categories, stories, gallery, contact details, and customer reviews.
- **🛵 Online Ordering**: Quick access to Zomato Gorakhpur (Taramandal) and Swiggy Gorakhpur (Paidleganj).

---

## 🛠️ Technology Stack
- **Frontend**: Semantic HTML5, Vanilla Modern CSS3 (Dark Royal Theme, Glassmorphism, CSS Grid & Flexbox), Vanilla ES6+ JavaScript.
- **Backend / API**: Lightweight Python 3 HTTP Server (`server.py`) with RESTful JSON endpoints.
- **Data Store**: Structured JSON persistence (`data/site-data.json`).

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/anandidubey13/Rajasthani-Tadka.git
cd Rajasthani-Tadka
```

### 2. Run the Local Server
No third-party packages or `pip install` required:
```bash
python3 server.py
```

### 3. Open in Browser
- **Main Website**: Visit [http://127.0.0.1:8090](http://127.0.0.1:8090)
- **Admin Studio CMS**: Visit [http://127.0.0.1:8090/admin.html](http://127.0.0.1:8090/admin.html)
